# v2.0 攻击动作本地掷骰执行记录

## 目标

把角色卡动作页的攻击条目从静态信息升级为可点击操作，让战斗中最常用的“掷命中 + 查看伤害公式”一步完成。

## 已完成范围

- 攻击动作 `ListTile` 支持点击。
- 点击后使用注入的 `DiceRoller` 掷 `d20 + 命中加值`。
- 结果通过 `SnackBar` 展示，例如：
  - `长弓：d20+4 = 24，伤害 1d8+2 穿刺`
- 攻击动作仍从背包中的可识别武器推导，保持当前 MVP 的轻量实现。

## 测试覆盖

- `character_pages_test.dart`
  - 覆盖点击长弓攻击动作后显示命中结果与伤害公式。
