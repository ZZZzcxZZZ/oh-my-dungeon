# v0.6 内容库 MVP 执行计划

状态：已完成

更新时间：2026-07-09

## 版本目标

DM 可以导入可扩展内容包，服务端在入库前给出明确校验错误；DM 可以为战役启用或禁用内容包，玩家可以查询当前战役可用的资料库条目。角色卡可以在 JSON 数据中引用法术、装备和特性，为后续自动补全、快捷动作和控场系统打基础。

## 边界

本版本做：
- Prisma 新增 `ContentPackage`、`ContentItem`、`CampaignContentPackage`、`ContentOverride`。
- 内容包 JSON 导入与 dry-run 校验。
- 首版内容类型：`spell`、`item`、`feat`、`feature`、`monster`、`condition`。
- 内容条目统一基础字段：`type`、`slug`、`name`、`description`、`structured`、`tags`、`sourceLabel`。
- 战役启用/禁用内容包。
- 战役可用内容查询，普通玩家只能看到自己所属战役启用的内容。
- DM 可以禁用单条内容。
- Flutter 新增“资料库/内容库”导航入口、内容包导入表单、战役启用入口、玩家查询列表。
- 角色卡 `data` 中允许保存 `contentRefs`，客户端提供基础编辑入口。

本版本不做：
- 完整 D&D 5e 官方内容内置。
- 内容富文本编辑器。
- 完整 JSON Schema 引擎和复杂规则片段执行。
- 角色升级自动化。
- 内容包导出、版本依赖解析和插件市场。

## 数据模型

### ContentPackage

- `id`
- `scope`: `user` / `campaign`
- `ownerUserId`
- `campaignId`
- `name`
- `version`
- `schemaVersion`
- `locale`
- `status`: `active` / `disabled` / `archived`
- `createdBy`
- `createdAt`
- `updatedAt`

### ContentItem

- `id`
- `packageId`
- `type`
- `slug`
- `name`
- `description`
- `structured`
- `tags`
- `sourceLabel`
- `schemaVersion`
- `createdAt`
- `updatedAt`

约束：同一个内容包内 `type + slug` 唯一。

### CampaignContentPackage

- `id`
- `campaignId`
- `packageId`
- `enabled`
- `enabledBy`
- `createdAt`
- `updatedAt`

约束：同一战役同一内容包只能有一条启用记录。

### ContentOverride

- `id`
- `campaignId`
- `baseContentItemId`
- `overrideType`: `disable`
- `derivedContentItemId`
- `patchData`
- `reason`
- `createdBy`
- `createdAt`
- `updatedAt`

v0.6 只实现 `disable`，保留 `patch` / `derive` 数据结构边界。

## API

### 内容包

- `POST /api/content/packages/import`
  - body: `{ dryRun?: boolean, package: ContentPackageImport }`
  - 登录用户可导入个人内容包。
  - `dryRun: true` 只返回校验结果，不落库。
  - `dryRun: false` 校验通过后创建包和条目。

- `GET /api/content/packages`
  - 返回当前用户创建的包，以及当前用户有权管理的战役包。

- `GET /api/content/items`
  - 支持 `type`、`q`、`packageId` 查询。
  - 只返回当前用户可见包中的条目。

- `GET /api/content/items/:id`
  - 当前用户可见时返回详情。

### 战役内容

- `POST /api/campaigns/:id/content/packages`
  - DM/owner 为战役启用或禁用内容包。

- `GET /api/campaigns/:id/content/available`
  - 战役成员查询当前战役可用内容。
  - 自动排除被 `ContentOverride disable` 的条目。

- `POST /api/campaigns/:id/content/overrides`
  - v0.6 只允许 DM/owner 创建 `disable` 覆盖。

## 客户端

导航：
- Player Mode：战役 / 角色 / 资料库 / 桌面 / 设置。
- DM Mode：战役 / 内容库 / 桌面 / 设置。
- 当前实现保持同一套 `NavigationBar`，根据模式调整第三项标签和页面重点。

资料库页：
- 未登录：显示登录提示。
- Player：选择战役后查看可用内容，支持类型筛选和搜索。
- DM：包含“我的内容包”与“战役启用”两个区域。
- 导入入口使用多行 JSON 输入框，先校验，再导入。
- Material 3 官方组件优先：`NavigationBar`、`SegmentedButton`、`DropdownMenu`、`SearchBar`、`FilledButton`、`ListTile`。

角色引用：
- 角色编辑页不做复杂 picker。
- 在角色 `data.contentRefs` 中保存：
  - `spells: string[]`
  - `items: string[]`
  - `features: string[]`
- 客户端提供基础文本编辑和展示，为 v1.0 自动完成保留接口。

## 测试策略

服务端：
- 内容包校验单元测试：
  - 缺少 name/version/items 报错。
  - 不支持的 type 报错。
  - 同包重复 `type + slug` 报错。
  - 合法包通过校验。
- 内容 API e2e：
  - dry-run 不落库。
  - 导入成功后可以查询条目。
  - 非战役成员不能查战役可用内容。
  - DM 可以为战役启用包。
  - 玩家只能看到该战役启用且未禁用的条目。
  - DM 禁用单条内容后，玩家查询不到。
  - 导入与禁用写入 JournalEntry。

客户端：
- `ContentApiClient` 单元测试覆盖 import/list/available/override。
- `ContentController` 单元测试覆盖校验、导入、战役查询。
- widget 测试覆盖导航出现资料库入口、未登录状态、导入错误展示。
