# 引路者（部分声明示范：只写到 5 级）

用来验证契约里的"**部分声明是一等功能**"（`docs/specs/2026-09-10-rules-contract-design.md` §3.12）：
自制职业**不必写完 1–20 级**，作者只声明设计过的部分。

## 这份包故意"没写完"

| 写法 | 含义 |
|---|---|
| `"progression": [{"levels":[1]…}, {"levels":[3]…}, {"levels":[5]…}]` | 只声明 1、3、5 级；**2 级与 4 级刻意跳过**，不写空壳步骤，也不报错 |
| `"prepared": [2,3,4,5,6]` | **短数组合法**：只声明 1–5 级；6 级及以上沿用第 5 级的值 |
| `"cantrips": [2,2,2,2,3]`、`"maximumSpellLevel": [1,1,1,2,2]` | 同上 |
| `"slots": {"1":{…},"3":{…}}` | 稀疏：只声明 1 级与 3 级。**低于最早声明等级的等级是"未声明"**（不会借用 3 级的法术位），按优先级回退到 `archetype` |
| `"maximum": {"table":[1,1,2,2,3]}` | 资源上限也允许短数组 |
| `"maximum": {"table":{"3":1,"5":2}}` | 稀疏资源表 |

## 界面必须如实呈现（不许静默变 0）

同一个 `declaredLevels` 数据源，出现在：

1. **导入预览** —— 副标题显示"职业声明：1–5 级"（信息样式，非错误色）；
2. **资料库规则视图** —— 顶部显示声明范围；
3. **创建向导** —— 等级滑杆把 1–5 级画成已声明区间、6–20 级画成未声明区间；滑到 6 级以上时出现信息条
   "该职业未声明 6 级以上内容，你仍可继续（数值按未声明处理）"；
4. **升级页** —— 目标等级超出声明范围时在"确认升级"上方显示同一条信息条；
5. **角色卡** —— 法术位/职业资源在未声明等级显示"该职业未声明该等级的内容"，**而不是 0**。
