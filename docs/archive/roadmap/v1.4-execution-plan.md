# v1.4 角色卡运行态执行计划

更新时间：2026-07-10

## 目标

让角色卡开始承载跑团现场高频修改的数据：临时 HP、灵感、状态条件、死亡豁免等。第一阶段沿用现有 Character `data.runtime` JSON，不立刻改服务端 schema。

## 当前已完成

- `CharacterSheet` 新增运行态 getter：
  - `runtimeMap`
  - `temporaryHp`
  - `inspiration`
  - `conditions`
  - `deathSaveSuccesses`
  - `deathSaveFailures`
- `CharacterDetailPage` 新增“状态”标签页。
- 状态页显示：
  - 临时 HP
  - 灵感
  - 死亡豁免
  - 状态条件列表
- `CharacterController.updateRuntimeState` 支持合并保存运行态，不覆盖已有 `contentRefs`。
- 状态标签页新增快捷操作：
  - 临时 HP +1 / -1
  - 获得 / 消耗灵感
  - 添加常用状态：中毒、倒地、震慑
  - 删除已有状态
- `CharactersTabPage` 已将角色详情页运行态更新接入 `CharacterController.updateRuntimeState`。
