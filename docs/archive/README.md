## 使用规则

1. 当前开发从 [`../README.md`](../README.md) 与仓库根 [`../../README.md`](../../README.md) 开始。
2. 历史文件保留原文件名，便于 Git 历史与旧链接检索。
3. 历史文档中的版本号（含 `v0.2`–`v2.x`）不代表当前发布版本。
4. 历史文档中的 Actor、Room、Session、Encounter 与战斗入口不代表当前产品模型。
5. 需要恢复历史方案时，必须先与当前代码和主文档重新对照后再动手。
