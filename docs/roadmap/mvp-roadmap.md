# MVP 版本路线图

> 历史说明：本文件保留早期拆分版本的规划记录。项目现在统一收束为 `0.1` 开发线，以下 `v0.2`、`v0.3` 等标题不再代表对外版本号或封版状态。实际推进顺序以 `docs/roadmap/current-execution-status.md` 和 `docs/roadmap/v0.1-unified-mvp-plan.md` 为准。

## v0.1 工程骨架

目标：项目能跑起来，开发和部署路径打通。

包含：

- Monorepo 结构。
- Flutter 空壳 App。
- NestJS 空壳服务端。
- PostgreSQL + Prisma。
- Docker Compose。
- `.env.example`。
- `/health`。
- `/.well-known/dnd-tool-server`。
- 基础 CI：lint、test、analyze。
- 基础 README。

验收标准：

- 开发者可以本地启动服务端和数据库。
- Flutter 可以连接到本地服务器。
- 客户端可以添加服务器并测试连接。
- Docker Compose 可以一键启动服务端。

## v0.2 账号、服务器、双模式

目标：用户能连接自托管服务器、注册登录，并在 Player/DM 模式之间切换。

包含：

- 客户端服务器列表。
- 添加、编辑、删除服务器。
- 按服务器保存登录状态。
- 注册、登录、JWT。
- 首次注册用户成为 Server Admin。
- Player / DM 模式切换。
- 基础设置页。

验收标准：

- 客户端可添加多个服务器。
- 不同服务器账号状态隔离。
- 用户登录后能切换 Player/DM 模式。
- 服务端能控制是否允许注册。

## v0.3 战役与成员

目标：DM 能创建战役，玩家能加入战役。

包含：

- DM 创建战役。
- 战役列表。
- 邀请码。
- 玩家输入邀请码加入。
- CampaignMember 权限。
- DM 成员管理基础版。
- Player 战役列表。
- DM 战役列表。

验收标准：

- DM 可以创建一个战役。
- 玩家可以用邀请码加入。
- 服务端能区分 owner、dm、player。
- 玩家不能访问未加入的战役。

## v0.4 跑团桌面基础版

目标：一场团能在线开始跑。

包含：

- Session 创建、开启、结束。
- 公共聊天。
- 公开骰。
- DM 暗骰。
- 在线成员。
- 基础事件日志 JournalEntry。
- WebSocket 房间广播。

验收标准：

- DM 可以开启一次跑团会话。
- 玩家进入同一个 Session。
- 聊天实时同步。
- 掷骰实时同步并落库。
- DM 暗骰只有 DM 可见。
- Session 结束后能查看日志。

## v0.5 角色卡基础版

目标：玩家能创建和维护可用于跑团的角色。

包含：

- 角色列表。
- 角色创建。
- 基础信息。
- 六属性。
- HP、AC、速度、先攻。
- 技能、豁免。
- 装备与货币基础版。
- 角色绑定战役。
- DM 查看战役角色。
- HP 快速调整。

验收标准：

- 玩家能创建角色并绑定到战役。
- 角色卡能自动计算常用数值。
- 玩家能编辑自己的角色。
- DM 能查看并调整战役内角色 HP 和状态。
- 角色变更写入日志。

## v0.6 内容库 MVP

目标：DM 可以管理可扩展资料，玩家可以查询和引用。

包含：

- 系统基础库结构。
- 内容包模型。
- 法术。
- 装备和物品。
- 特性和专长。
- 怪物和 NPC 简表。
- 状态条件。
- JSON 导入。
- 导入校验。
- 战役启用和禁用内容。
- DM 派生基础条目。
- 玩家资料库查询。

验收标准：

- DM 能导入一个内容包。
- 导入前能看到校验错误。
- DM 能为战役启用或禁用内容。
- 玩家只能看到当前战役可用内容。
- 角色卡可以引用法术、装备和特性。

## v0.7 DM 控场基础版

目标：DM 可以管理一次简单战斗。

包含：

- NPC 管理。
- 遭遇创建。
- 遭遇参与者。
- 先攻队列。
- 回合推进。
- 怪物 HP 和 AC。
- 状态和效果基础版。
- 玩家可见性控制。

验收标准：

- DM 可以创建遭遇。
- DM 可以把玩家角色和 NPC 加入先攻。
- DM 可以推进回合。
- DM 可以调整怪物 HP 和状态。
- 玩家只能看到 DM 允许公开的信息。
- 战斗过程写入日志。

## v0.8 检定请求与快捷动作

目标：跑团操作开始变顺手。

包含：

- DM 发起检定请求。
- 指定全体、单人或角色。
- 公开 DC 或隐藏 DC。
- 玩家一键响应。
- 技能和豁免快捷骰。
- 攻击和伤害快捷动作基础版。
- 骰子历史。

验收标准：

- DM 能发起全员感知检定。
- 玩家能一键掷骰。
- DM 能看到提交状态和结果。
- 结果自动进入聊天和日志。

## v1.0 自托管公测版

目标：一个朋友团可以真的长期使用。

包含：

- 备份和恢复文档。
- 部署文档完善。
- 基础 Server Admin 设置。
- 内容包导入导出稳定。
- 角色卡中自动完成。
- DM 控场基础稳定。
- 跑团日志可检索。
- Flutter Android、Web、Desktop 至少稳定两个端。

验收标准：

- 普通用户能按文档部署服务器。
- 客户端能连接自托管服务器。
- DM 能创建战役并开团。
- 玩家能加入、建角色、跑团。
- 核心数据可备份恢复。

## v1.0 暂不包含

- 地图战棋。
- 战争迷雾。
- 语音和视频。
- 完整自动升级规则。
- 完整官方内容库。
- 插件市场。
- AI 跑团总结。
- 复杂模组编辑器。
- 多服务端联邦。
