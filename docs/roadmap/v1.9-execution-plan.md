# v1.9 角色卡本地检定掷骰执行记录

## 目标

让角色卡动作页从“查数值”进一步变成“可操作”。本阶段先落地本地掷骰反馈，为之后接入房间 / 场次日志和 WebSocket 同步打基础。

## 已完成范围

- `CharacterDetailPage` 支持注入 `DiceRoller`。
- 动作页的常用检定 `InputChip` 可以点击掷 `d20 + 修正值`。
- 掷骰结果通过 `SnackBar` 显示，例如：
  - `察觉：d20+4 = 24`
- 测试中可注入固定随机数，保证结果稳定。

## 测试覆盖

- `character_pages_test.dart`
  - 覆盖点击动作页 `察觉 +4` 后显示本地掷骰结果。
  - 保留角色卡概览、状态、动作、装备、创建向导测试，确认无回归。
