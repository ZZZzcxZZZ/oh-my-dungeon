# 0.1 Campaign Chat Progress - 2026-07-11

## Completed

- Added the server-side `CampaignChatMessage` Prisma model.
- Added campaign-scoped chat endpoints:
  - `GET /api/campaigns/:id/messages`
  - `POST /api/campaigns/:id/messages`
- Campaign chat now reuses Campaign membership authorization. Non-members cannot read or send messages.
- Flutter `CampaignApiClient` supports listing and sending campaign messages.
- Flutter `CampaignController` owns campaign chat message state.
- `CampaignChatPage` now loads persisted campaign messages and sends `say` / `action` messages through the API.
- Sent messages include the bound character summary: `characterId`, `displayName`, and `avatarUrl`.
- Local PostgreSQL schema was synchronized with `prisma db push` without resetting data.

## Realtime Update

- Added server `CampaignsGateway` on the `/campaigns` Socket.IO namespace.
- Campaign members can join `campaign:<id>` rooms through `campaign:join`.
- Non-members are rejected before joining campaign realtime rooms.
- `CampaignsService.sendMessage` now broadcasts `campaign:message:new` after persistence.
- Added Flutter `CampaignSocketService` and `SocketIoCampaignSocketService`.
- `CampaignController` connects to campaign chat realtime, appends remote messages, and deduplicates echoed HTTP/WebSocket messages by `message.id`.
- `CampaignChatPage` joins realtime on entry and disconnects on exit.
- Dependency injection now allows widget tests to use `NoopCampaignSocketService` instead of opening real sockets.
- Unified the Flutter client package version to `0.1.0+1`.
- Content package validation now accepts core 0.1 player-facing content types: `spell`, `item`, `equipment`, `species`, `class`, `background`, `feat`, `feature`, `monster`, and `condition`.
- The content creation GUI exposes item/equipment/species/class/background/feat options instead of requiring JSON editing.
- Campaign chat member button now opens a Material 3 member sheet backed by `CharacterCampaignBinding`.
- The member sheet shows each bound character's avatar initial, name, class/species summary, HP/AC, conditions, and visibility.
- The campaign chat `+` menu now opens the bound character sheet directly, keeping the campaign room as the primary play surface.
- The campaign chat `+` menu now includes a quick dice sheet. Players can roll common dice such as `d20`, and the result is sent back into the campaign chat as a `roll` message.
- The campaign chat `+` menu now includes a campaign content quick reference sheet backed by `ContentController`.
- The quick reference sheet supports search, type filtering, item listing, and a readable item detail view without leaving the chat room.
