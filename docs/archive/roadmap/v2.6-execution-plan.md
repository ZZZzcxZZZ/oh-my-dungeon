# v2.6 Material 3 动态主题风格执行记录

## 目标

改进设置页的主题取色能力，让客户端不只是切换 seed color，而是能使用 Flutter / Material 3 官方的动态配色变体。这样开源部署者可以按自己的桌面、投屏或移动端偏好选择更稳定或更鲜明的视觉风格。

## 已完成范围

- `AppPreferences` 新增 `dynamicSchemeVariant` 偏好。
- 默认值为 `tonalSpot`，对应 Material 3 标准主题色生成方式。
- 偏好存储新增 `app_preferences.dynamic_scheme_variant`。
- `AppPreferencesController` 新增 `setDynamicSchemeVariant`。
- `DndTableApp` 在构建浅色 / 深色 `ColorScheme.fromSeed` 时传入官方 `DynamicSchemeVariant`：
  - `tonalSpot`
  - `fidelity`
  - `expressive`
  - `vibrant`
  - `neutral`
- 设置页外观区域新增 `主题风格` 下拉项，并继续保留 seed color 与高对比开关。
