# v2.14 角色卡状态条件选择器执行记录

## 目标

继续把角色卡状态页推进为跑团现场可用的运行态面板。v2.13 已补齐 HP 数值快改和休息入口，本版本把状态条件从少量固定按钮升级为 Material 3 风格的搜索选择器，并允许玩家或 DM 输入自定义状态。

## 已完成范围

- 状态条件选择：
  - 新增 `搜索或输入自定义状态` 输入框。
  - 常用状态通过 `ActionChip` 展示，点击即可加入当前角色状态。
  - 输入关键字时只显示匹配状态，例如搜索 `失明` 时不再展示无关状态。
  - 当前已拥有的状态不会重复出现在可选项中。
- 自定义状态：
  - 输入非空且不属于已有常用状态时，显示 `添加自定义状态`。
  - 自定义状态加入后清空输入框，便于继续操作。
  - 空白输入和重复状态不会提交。
- 当前状态展示：
  - 当前状态继续使用 `InputChip`，支持删除。
  - 删除状态后通过现有 `CharacterRuntimeUpdate.conditions` 提交完整状态列表。
- 常用状态池：
  - 覆盖失明、魅惑、耳聋、恐慌、擒抱、失能、隐形、麻痹、石化、中毒、倒地、束缚、震慑、昏迷和力竭 1-6。

## 测试覆盖

- `character_pages_test.dart`
  - 新增测试覆盖搜索常用状态、添加常用状态、添加自定义状态和删除状态。
  - 迁移旧的“添加震慑”测试到新选择器，保留 runtime 回调断言。

## 不做事项

- 不新增服务端状态条件模型。
- 不接入内容包中的状态定义；后续可把常用状态池替换为内容包 + 房规来源。
- 不根据状态自动影响动作、检定、AC、速度或施法。
- 不把状态变化写入 Session Log；该能力仍留给后续具备当前 Session 上下文的版本。

## 后续建议

- v2.15：增加设置项控制 HP、休息和状态变更是否写入当前 Session Log。
- v2.16：把状态条件来源接入内容包，支持 DM 在战役级启用房规状态。
- v2.17：在动作页加入状态影响提示，例如中毒、倒地、束缚和失能对检定/攻击的影响。
