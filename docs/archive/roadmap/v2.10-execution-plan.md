# v2.10 角色列表紧凑模式执行记录

## 目标

让设置页的 `列表密度` 不再只是保存项，而是真正影响角色页。对于桌面宽屏、移动端小屏和跑团中快速查找角色的场景，紧凑列表能减少滚动和视觉噪音。

## 已完成范围

- `CharactersTabPage` 读取 `appPreferencesController.preferences.compactLists`。
- 普通模式保持原有卡片：
  - 展示角色摘要。
  - 使用 Chip 展示 HP、AC、先攻、熟练。
  - 保留 HP 快捷按钮和角色操作菜单。
- 紧凑模式新增：
  - 更小外边距和列表间距。
  - `ListTile.dense` 与 `VisualDensity.compact`。
  - 单行战斗摘要：`HP x/y · AC n · 先攻 +n`。
  - `紧凑角色列表` 标记，便于测试和可访问性确认。
