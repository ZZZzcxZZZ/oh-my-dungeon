# 角色创建、角色卡与设置体验 Roadmap

更新时间：2026-07-10

## 总目标

把角色系统从“可保存字段”升级为“玩家每场团都会使用的数字角色卡”。后续版本以 D&D Beyond 的角色创建与管理体验为参照，但只模仿产品结构、交互密度和信息架构；不复制商标、美术、官方闭源内容或专有文案。实现时采用 Flutter Material 3 和开源自托管内容包体系。

## 产品原则

- 创建角色必须有引导，不让新玩家直接面对长表单。
- 角色卡必须服务于跑团现场，高频数据可直接修改。
- D&D 2024 与 2014 规则差异必须显式建模，不把旧版假设写死。
- 每个自动计算字段都应能说明来源，并允许玩家/DM 手动覆盖。
- 设置页应使用 Material 3 的系统化偏好分组，并优先支持 Google Dynamic Color。

## v1.3 角色创建器

目标：提供 D&D Beyond-like 的创建入口，让玩家可以从快速创建或标准引导开始。

范围：

- 新建角色入口先进入“创建方式选择”。
- Quick Build 覆盖：规则集、职业、物种、背景、等级、名字。
- Standard Build 骨架覆盖：来源、职业、起源、属性、熟练、装备、法术、详情、审核。
- D&D 2024 用“物种”作为 UI 主术语，兼容旧数据的“种族”字段。
- 创建草稿自动填充基础能力值、HP、AC、速度、先攻和推荐装备。
- 创建完成后仍调用现有 Character API，不改服务端模型。

验收：

- 玩家点击“新角色”后先看到创建方式选择。
- Quick Build 可以在少量输入后生成可保存的角色草稿。
- Standard Build 至少具备完整步骤导航、完成度提示和 Review 页。
- 现有编辑已有角色流程不回归。

## v1.4 角色卡运行态

目标：把角色卡变成跑团时可直接操作的状态面板。

范围：

- 当前 HP、最大 HP、临时 HP。
- 伤害、治疗、设定值快捷操作。
- 死亡豁免。
- 灵感。
- 状态条件：中毒、倒地、震慑、魅惑、隐形、力竭等级、自定义状态。
- 短休/长休恢复入口。
- HP 和状态变化写入 Session Log 的接口预留。

验收：

- 玩家无需进入编辑页即可调整 HP、临时 HP、状态和灵感。
- 角色卡总览第一屏显示当前可战斗状态。
- 状态和资源修改有清晰的确认或撤销路径。

## v1.5 装备、背包与货币

目标：装备从纯文本列表升级为可管理物品系统。

范围：

- 物品数量、装备/卸下、同调、消耗品、弹药、充能。
- 容器与分组：背包、随身、仓库、自定义容器。
- 货币快捷增减与交易记录。
- 重量/负重可选显示。
- 物品来源：内容包、手动创建、战役奖励。

验收：

- 玩家可在角色卡内直接消耗治疗药水、弹药和充能物品。
- 装备 AC 或攻击相关物品时能显示影响提示。
- 货币修改不再需要编辑整张角色卡。

## v1.6 法术、动作与掷骰

目标：角色卡内的可执行动作能直接服务跑团桌面。

范围：

- 动作、奖励动作、反应、其他动作分区。
- 攻击、伤害、豁免 DC、法术攻击加值。
- 法术准备、取消准备、法术位消耗与恢复。
- 专注状态。
- 点击掷骰进入当前 Session Game Log。
- 默认可见性：公开、仅 DM、仅自己。

验收：

- 常用技能、攻击和法术能一键掷骰。
- 掷骰结果能和当前 Session 关联。
- 法术位和资源消耗可从角色卡直接修改。

## v1.7 规则源与内容策略

目标：正式支持 D&D 2024 / 2014 / 混合规则源。

范围：

- RulesetPreference：2024、2014、mixed。
- Legacy 内容标记。
- CampaignContentPolicy 控制战役可用内容。
- 角色字段来源说明：职业、背景、物种、专长、装备、手动覆盖。
- 来源冲突提示。

验收：

- 2024 角色创建不再假设“种族提供属性加值”。
- 2014 内容可继续创建和显示。
- 混合模式有明显提示，不悄悄混用规则。

## v1.8 设置与 Material 3 设计系统

目标：把设置页从功能堆叠升级为系统化偏好中心。

范围：

- 外观：系统/浅色/深色、Google Dynamic Color、Material 3 seed fallback。
- 字体缩放、列表密度、角色卡默认标签。
- 规则：默认规则集、默认创建方式、Legacy 内容显示。
- 跑团：默认骰子、掷骰确认、默认掷骰可见性、HP 修改是否写日志。
- 角色卡：显示来源、显示负重、折叠低频字段、显示 2024/2014 差异提示。
- 服务器：连接测试、清除本服务器本地缓存、管理员入口。

验收：

- Android 支持系统动态取色；其他平台使用合法 Material 3 seed palette。
- 设置分组清晰，低频设置不挤占跑团高频路径。
- 偏好按服务器或本地维度明确保存。

## v1.9 DM 侧角色管理

目标：DM 能在战役和桌面中有效管理玩家角色。

范围：

- DM 查看战役角色。
- DM 给角色添加/移除状态。
- DM 调整 HP、临时 HP、灵感和资源。
- DM 审核玩家自定义内容引用。
- DM 从角色列表发起检定请求。

验收：

- DM 不需要打开玩家设备即可管理战斗状态。
- 所有 DM 修改进入 Journal 或 Session Log。
- 玩家可看到 DM 公开的状态变化。

## 当前执行版本

现在进入 v1.3。第一阶段只做客户端，不改服务端模型：

1. 写测试锁定创建方式选择和 Quick Build 行为。
2. 重构 `CharacterEditorPage`，新建角色时显示创建方式入口。
3. Quick Build 生成一份完整 `CharacterEditDraft`。
4. Standard Build 提供步骤骨架和 Review 页。
5. 保持编辑已有角色仍进入完整表单。
