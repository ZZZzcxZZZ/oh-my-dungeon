# v1.1 Character, Settings, and Material 3 UI Implementation Plan

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 将 MVP 的角色页、设置页和主导航从原型形态升级为简明可用的 Flutter Material 3 应用体验。

**架构：** 保留现有 Nest/Flutter 分层，不扩展战役、战斗或 WebSocket 边界。本轮在客户端新增 D&D 5e 角色规则领域模块，贯通已有 Character JSON 字段，并拆出角色详情/编辑页面以降低 `characters_tab_page.dart` 的复杂度。

**技术栈：** Flutter Material 3、Dart 单元测试和 Widget 测试、现有 Nest Character API。
