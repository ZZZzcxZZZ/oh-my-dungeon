# v2.3 角色卡结构化掷骰事件执行记录

## 目标

为“角色卡掷骰同步到房间 / 场次日志”打基础。角色卡不能只把结果写进 `SnackBar`，否则后续只能从 UI 文本反解析。它需要产出结构化事件，让场次页、WebSocket、日志系统都能复用。

## 已完成范围

- 新增 `CharacterRollEvent`：
  - `label`
  - `notation`
  - `total`
  - `summary`
- `CharacterDetailPage` 新增 `onRoll` 回调。
- 常用检定触发结构化事件，例如：
  - `label: 察觉`
  - `notation: d20+4`
  - `total: 24`
  - `summary: 察觉：d20+4 = 24`
- 攻击动作触发结构化事件，例如：
  - `label: 长弓`
  - `notation: d20+4 / 1d8+2`
  - `total: 命中总值 + 伤害总值`
  - `summary: 长弓：d20+4 = 24，伤害 1d8+2 = ... 穿刺`
- 现有本地 `SnackBar` 反馈保留，结构化事件作为额外输出，不破坏当前角色卡使用体验。

## 测试覆盖

  - 验证完整角色页测试无回归。
