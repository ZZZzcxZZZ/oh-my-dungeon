# v2.1 攻击动作伤害掷骰执行记录

## 目标

让角色卡攻击动作更贴近真实跑团流程：玩家点击一次攻击，不仅得到命中掷骰，也能立即得到伤害骰结果，减少战斗中反复切换和心算。

## 已完成范围

- 攻击动作点击后同时掷：
  - `d20 + 命中加值`
  - 武器伤害公式，例如 `1d8+2`
- 结果继续通过 `SnackBar` 展示，例如：
  - `长弓：d20+4 = 24，伤害 1d8+2 = ... 穿刺`
- 攻击列表仍保留静态摘要：
  - 武器名称
  - 命中加值
  - 伤害公式与伤害类型
- 实现保持轻量：仍复用角色卡注入的 `DiceRoller`，为之后接入房间 / 场次日志保留统一掷骰入口。

## 测试覆盖

- `character_pages_test.dart`
  - 先修改攻击动作测试为失败状态，要求伤害公式后出现 `=`，证明伤害骰被实体掷出。
  - 实现后目标测试通过。

- v2.2：为攻击动作加入优势 / 劣势切换。
- v2.3：将角色卡掷骰写入当前房间或场次日志。
