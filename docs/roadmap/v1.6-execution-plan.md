# v1.6 角色卡动作经济与派生战斗数据执行记录

## 目标

让角色卡动作页更像线上跑团时真正会打开的页面：战斗中需要快速确认命中、伤害、施法 DC、附赠动作和反应，而不是只显示少量通用检定。

## 已完成范围

- 动作页从“常用动作”扩展为：
  - 常用检定
  - 攻击动作
  - 施法
  - 附赠动作
  - 反应
- `Dnd5eRules` 新增基础派生能力：
  - 武器识别：长弓、短剑、匕首、长剑、法杖及英文别名。
  - 命中加值：属性修正 + 熟练加值。
  - 伤害公式：武器伤害骰 + 属性修正。
  - 施法关键属性：支持常见 5e / 2024 职业中英文名称。
  - 法术豁免 DC：`8 + 熟练加值 + 施法属性修正`。
- 当前角色卡会从背包推导可识别武器，并显示例如：
  - `长弓`
  - `+4 命中`
  - `1d8+2 穿刺`
  - `法术豁免 DC 12`

## 测试覆盖

- `dnd5e_rules_test.dart`
  - 覆盖武器识别、命中、伤害公式、游侠施法属性与法术 DC。
- `character_pages_test.dart`
  - 覆盖动作页的攻击动作、施法、附赠动作、反应区域。
