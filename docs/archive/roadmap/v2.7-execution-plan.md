# v2.7 场次页默认骰子偏好落地执行记录

## 目标

让设置页的 `默认骰子` 不只是保存项，而是真正影响跑团时的常用操作。玩家或 DM 在场次页打开掷骰弹层时，应直接看到自己配置的默认表达式。

## 已完成范围

- `SessionDetailPage` 新增 `AppPreferencesController` 依赖。
- `TableTabPage` 与 `MainShell` 将同一个偏好控制器透传到场次页。
- 场次页 `掷骰` 弹层初始表达式从：
  - 固定 `1d20`
  - 改为 `appPreferencesController.preferences.defaultDice`
- 保持原有手动输入、公开 / DM / 暗骰可见性逻辑不变。

## 测试覆盖
