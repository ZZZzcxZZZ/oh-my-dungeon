# 战役资料库 Wiki 设计规格

## 目标

将资料库升级为战役内的规则百科。DM 导入一个完整的私有 PHB 包，服务端将其保存为
可搜索、可关联的条目；战役成员只读浏览，个人可收藏常用规则。

资料包是导入、导出与版本管理单位，条目是搜索、跳转、收藏和角色创建引用单位。

## 权限与边界

资料包属于一个战役。只有该战役的 `owner` 或 `dm` 可以导入、启用、停用和创建覆写；
成员只能读取已启用条目，且只能收藏自己的条目。所有权限由服务端成员角色验证。

私有 PHB JSON 只在导入时使用，正文持久化在用户的自托管服务器。它不进入仓库、种子
数据或发布产物。可再分发的 SRD 内容仍可使用 `system` 范围。

## 数据模型

`ContentPackage(scope: campaign, campaignId)` 绑定单个战役，导入成功后默认启用。
`ContentItem` 保留类型、正文、结构化字段、标签和来源。新增：

- `ContentItemLink`：源条目、目标条目、关系、显示标签与排序；导入引用通过包内
  `type + slug` 解析，未解析引用阻止导入。
- `UserContentFavorite`：`userId + contentItemId` 唯一的个人收藏。收藏不绕过战役
  可见性。

原始包只读；战役房规继续通过 `ContentOverride` 表达，不直接篡改导入数据。

## Wiki 与 Material 3 体验

资料库始终以当前战役为上下文。顶部使用 `AppBar`、`SearchBar` 和可滚动
`FilterChip`；列表使用 `ListTile`，收藏使用 `IconButton`。宽屏显示稳定的列表/详情
双栏，窄屏从列表进入全屏详情。避免嵌套大卡片。

职业详情采用“概览 / 等级特性 / 法术”标签。概览仅显示生命骰、主属性、豁免、熟练与
施法属性；等级特性按 1–20 级分组，使用 `ExpansionTile` 展开独立特性条目。关联条目
以可点击 `ListTile` 呈现，可继续跳转。

DM 操作收纳于 `MenuAnchor`：导入完整资料包、管理启用状态、创建覆写。导入对话先
dry-run 显示类型计数和链接错误，再确认导入当前战役；玩家不显示任何写入入口。

## 验收

- Player 调用导入 API 返回 403；DM 的包只对该战役成员可见。
- 导入支持条目链接；无效链接阻止导入。
- 成员可按关键词、类型、标签、收藏筛选，并只能修改自己的收藏。
- 职业特性可按等级展开并跳转；窄屏与宽屏不截断基础信息。
- `npm run check` 与 `flutter build web --release --pwa-strategy=none` 通过。
