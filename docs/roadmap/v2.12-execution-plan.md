# v2.12 角色卡运行态快改执行记录

## 目标

把角色卡的“状态”标签从展示页推进为跑团现场可直接操作的运行态面板。玩家最频繁修改的是当前 HP、临时 HP、灵感、状态条件和死亡豁免，本版本优先补齐无需进入完整编辑页即可完成的快改路径。

## 已完成范围

- 角色详情页状态标签：
  - 显示 `当前 HP 当前值/上限`。
  - 提供 `受到 1 点伤害` 与 `恢复 1 点 HP` 两个 Material 3 icon button。
  - 当前 HP 调整会限制在 `0..maxHp` 范围内。
  - 保留已有临时 HP、灵感和状态条件快改。
  - 新增死亡豁免成功/失败递增按钮，并限制在 `0..3` 范围内。
- 数据提交：
  - `CharacterRuntimeUpdate` 新增 `currentHp` 参数。
  - 角色列表打开详情页时，当前 HP 变更走 `CharacterController.updateCharacter`。
  - 临时 HP、灵感、状态条件、死亡豁免仍走 `updateRuntimeState`。
- 设置页：
  - “默认角色卡标签”补齐 `状态`、`特性`、`详情` 选项。
  - 玩家可把角色卡默认入口设置为状态页，服务高频跑团操作。

## 测试覆盖

- `character_pages_test.dart`
  - 新增测试：状态页可调整当前 HP 和死亡豁免，并通过回调提交正确字段。
  - 保持已有临时 HP、灵感和状态条件快改测试。
- `widget_test.dart`
  - 设置页测试覆盖“默认角色卡标签”下拉包含 `状态`。

## 不做事项

- 不改变服务端数据模型。
- 不新增 HP 批量伤害/治疗输入框。
- 不把 HP 修改写入 Session Log；该行为保留给后续带战役/场次上下文的版本。
- 不实现死亡豁免重置、短休和长休恢复流程。

## 后续建议

- v2.13：在状态页加入伤害/治疗数值输入、死亡豁免重置、短休/长休入口。
- v2.14：把角色卡快改与当前 Session Log/Journal 关联，并受设置项控制是否记录。
- v2.15：状态条件改为可搜索的 condition picker，并支持自定义状态。
