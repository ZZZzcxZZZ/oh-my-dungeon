# v0.7 DM 控场基础版执行计划

状态：已完成

更新时间：2026-07-09

## 版本目标

DM 可以为战役创建 NPC 和遭遇，把玩家角色或 NPC 加入先攻队列，开始遭遇、推进回合、调整参与者 HP/状态，并控制哪些参与者对玩家可见。战斗过程写入 `JournalEntry`，为后续检定请求、快捷动作和日志检索提供事件基础。

## 边界

本版本做：
- Prisma 新增 `Npc`、`Encounter`、`EncounterParticipant`。
- NPC 基础管理：创建、列表、编辑。
- 遭遇基础管理：创建、列表、详情、开始、推进回合、结束。
- 遭遇参与者：添加角色、添加 NPC/怪物快照、更新 HP/AC/initiative/隐藏状态/状态标签。
- 玩家可见性过滤：普通玩家只能看到未隐藏参与者。
- 战斗关键动作写入 `JournalEntry`。
- Flutter 新增简洁 DM 控场入口：战役选择、遭遇列表、创建遭遇、参与者列表、开始/推进/结束、HP 快捷调整。

本版本不做：
- 地图战棋、站位、距离、战争迷雾。
- 复杂怪物规则自动化。
- 完整 Effect 模型自动结算。
- WebSocket 遭遇实时广播。
- 复杂 NPC 富文本编辑器。

## API

### NPC

- `POST /api/campaigns/:id/npcs`
- `GET /api/campaigns/:id/npcs`
- `PATCH /api/npcs/:id`

### Encounters

- `POST /api/campaigns/:id/encounters`
- `GET /api/campaigns/:id/encounters`
- `GET /api/encounters/:id`
- `PATCH /api/encounters/:id`
- `POST /api/encounters/:id/participants`
- `PATCH /api/encounters/:id/participants/:participantId`
- `POST /api/encounters/:id/start`

- `POST /api/encounters/:id/end`

## 测试策略

服务端：
- e2e 先覆盖：
  - 非 DM 不能创建 NPC/Encounter。
  - DM 可以创建 NPC。
  - DM 可以创建遭遇并添加角色/NPC 参与者。
  - 玩家查看遭遇详情时看不到隐藏参与者。
  - 开始遭遇设置状态、round 和 currentTurnParticipantId。
  - 推进回合按 initiative/sortOrder 轮转并在回到第一位时增加 round。
  - HP/状态更新写入 JournalEntry。
  - 结束遭遇写入 JournalEntry。

客户端：
- API client 测试覆盖 NPC/Encounter/participant/start/advance/end。
- controller 测试覆盖加载遭遇、创建遭遇、HP 调整。
- widget 测试覆盖 DM 模式下出现“控场”入口或桌面内控场区域。
