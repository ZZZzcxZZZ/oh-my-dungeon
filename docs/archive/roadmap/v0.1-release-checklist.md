# v0.1 工程骨架封版清单

更新时间：2026-07-09

## 目标

v0.1 的目标不是继续扩展跑团业务，而是让项目具备可复现的开发、测试和自托管启动路径。

## 验收项

- [x] Monorepo 根结构存在。
- [x] `apps/client_flutter` Flutter 客户端存在。
- [x] `apps/server_nest` NestJS 服务端存在。
- [x] `packages/api_contracts` 边界存在。
- [x] `packages/dnd_rules` 边界存在。
- [x] `infra` 边界存在。
- [x] PostgreSQL + Prisma 配置存在。
- [x] Docker Compose 配置存在。
- [x] `.env.example` 存在。
- [x] `GET /health` 存在，并探测 Prisma 数据库连接。
- [x] `GET /.well-known/dnd-tool-server` 存在。
- [x] 客户端可添加和保存服务器 profile。
- [x] 客户端可读取服务器 well-known metadata。
- [x] 客户端支持 Player/DM 模式切换。
- [x] CI 覆盖 server lint/test。
- [x] CI 覆盖 Flutter analyze/test。
- [x] CI 覆盖 Docker Compose config。

## v0.1 内允许保留但不继续扩展的原型

- `/api/rooms`。
- `/api/rooms/:roomId/rolls`。
- Flutter 房间列表与房间详情页。
- D20 和骰子表达式掷骰。

这些能力后续必须在 v0.3/v0.4 中归并到正式的 Campaign / Session / Table 模型。

## v0.1 封版验证命令

版本封版时运行：

```powershell
npm run lint:server
npm run test:server
npm run analyze:client
npm run test:client
npm run docker:config
```

如果涉及依赖、脚本、CI 或 Docker，再运行：

```powershell
npm run doctor
```

## 下一步

v0.1 封版后进入 v0.2，不继续堆 room 原型。v0.2 的唯一主线是账号、服务器隔离、JWT 和 Server Admin。
