# v1.5 角色卡装备与资源快捷管理执行记录

## 目标

让角色卡更接近线上跑团时的真实使用方式：玩家和 DM 不应每次修改装备数量、消耗品或金币都进入完整编辑页，而应该在角色卡中直接完成高频变更。

## 已完成范围

- 角色详情页装备标签页改为可交互面板。
- 装备支持 `+1` / `-1` 快捷调整数量。
- 消耗品支持一键消耗，当前识别：
  - `consumable: true`
  - 名称包含“药水 / potion / 卷轴 / scroll / 口粮 / ration”
- 货币支持按币种 `+1` / `-1` 快捷调整，并限制不低于 0。
- 新增角色卡装备同步回调 `CharacterInventoryUpdate`。
- 新增 `CharacterController.updateInventoryAndCurrency`，从角色详情页保存到服务端。
- 保持装备页为 Material 3 简洁列表与描边控制，不引入复杂嵌套卡片。

## 测试覆盖

- `character_pages_test.dart`
  - 验证装备标签页可以调整长弓数量。
  - 验证治疗药水可以一键消耗。
  - 验证 `gp` 可以快捷增加并触发保存回调。
- `character_controller_test.dart`
  - 验证控制器把背包与货币更新传递给 `CharacterClient.updateCharacter`。

- v1.7：补充 2024 规则下的行动经济面板，包括动作、附赠动作、反应、豁免 DC、武器攻击与伤害公式。
