# v2.2 优势 / 劣势掷骰模式执行记录

## 目标

让角色卡动作页支持 D&D 战斗和检定中最常见的临场修正：优势与劣势。玩家不应每次手动掷两次再心算取高或取低。

## 已完成范围

- 动作页新增 `掷骰模式` 分段控件：
  - 普通
  - 优势
  - 劣势
- 常用检定支持当前掷骰模式：
  - 普通：`察觉：d20+4 = 24`
  - 优势：`察觉：优势 d20(5, 20)+4 = 24`
  - 劣势：`察觉：劣势 d20(15, 2)+4 = 6`
- 攻击动作复用同一套 d20 掷骰模式，并继续掷伤害。
- 连续掷骰会清除当前 `SnackBar`，新结果立即显示，避免跑团中快速操作时结果排队。

## 测试覆盖

- `character_pages_test.dart`
  - 先写失败测试，确认页面原本没有优势 / 劣势控件。
  - 验证优势取两次 d20 的较高值。
  - 验证劣势取两次 d20 的较低值。
  - 验证完整角色页测试无回归。
