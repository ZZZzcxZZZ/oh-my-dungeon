# v2.8 场次页掷骰确认偏好落地执行记录

## 目标

让设置页的 `掷骰确认` 真正影响跑团场次操作。开启后，玩家或 DM 从场次页掷骰时需要先确认，减少误触导致的公开掷骰污染时间线。

## 已完成范围

- `SessionDetailPage` 在掷骰弹层提交后读取 `confirmBeforeRoll`。
- 开启确认时显示 `确认掷骰` 对话框。
- 用户点击 `取消` 时不创建掷骰。
- 用户点击 `确认` 后才调用 `SessionController.createRoll`。
- 默认骰子、可见性、actorName 逻辑保持不变。

## 测试覆盖

- `session_detail_page_test.dart`
  - 先写失败测试，验证开启确认后原本不会出现确认对话框。
  - 验证确认前 `SessionClient.createRoll` 未调用。
  - 验证点击 `确认` 后才创建掷骰，并保留默认骰子表达式。
