# v2.13 角色卡状态页数值快改执行记录

## 目标

继续把角色卡状态页推进为跑团现场的高频操作面板。v2.12 已支持当前 HP 的 `+1/-1` 快改，本版本补齐实际桌面上更常见的“输入一个伤害或治疗数值后应用”，并提供休息与死亡豁免重置入口。

## 已完成范围

- 生命快改：
  - 新增 `数值` 输入框，默认值为 `1`。
  - 新增 `受到伤害` 按钮，按输入数值扣减当前 HP。
  - 新增 `恢复 HP` 按钮，按输入数值恢复当前 HP。
  - 当前 HP 仍限制在 `0..maxHp` 范围。
  - 无效或非正数输入按 `1` 处理，避免跑团现场误填导致无响应。
- 死亡豁免：
  - 新增 `重置死亡豁免` 按钮，同时把成功和失败次数归零。
  - 保留成功/失败单独递增按钮。
- 休息：
  - 新增 `短休` 按钮：当前版本重置死亡豁免。
  - 新增 `长休` 按钮：当前 HP 恢复到上限，临时 HP 清零，死亡豁免清零。
- 数据提交：
  - 数值伤害/治疗通过 `currentHp` 提交。
  - 重置与休息通过现有 `CharacterRuntimeUpdate` 一次提交可表达的字段。

## 测试覆盖

- `character_pages_test.dart`
  - 新增测试覆盖数值伤害、数值治疗、死亡豁免重置、短休和长休。
  - 调整旧状态页测试，在状态页变长后先滚动到目标按钮再点击。

## 不做事项

- 不新增复杂的伤害类型、抗性、易伤或免疫计算。
- 不实现 Hit Dice 消耗和职业资源恢复。
- 不把休息写入 Session Log；该能力留给具备当前 Session 上下文的后续版本。
- 不改变服务端模型。

## 后续建议

- v2.14：把状态条件改为可搜索 condition picker，支持更多 D&D 常用状态和自定义状态。
- v2.15：增加设置项控制 HP/休息变更是否写入当前 Session Log。
- v2.16：在角色卡动作页加入临场修正输入，例如 bless、guidance、cover 和自定义加值。
