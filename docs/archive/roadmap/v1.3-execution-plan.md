# v1.3 角色创建器执行计划

更新时间：2026-07-10

## 目标

把新建角色从长表单改为 D&D Beyond-like 的引导式创建体验。第一阶段只做客户端，不改变服务端 Character 模型。

## 范围

- 新建角色入口显示创建方式选择。
- Quick Build 提供 D&D 2024 默认创建路径。
- Standard Build 提供完整步骤骨架。
- 编辑已有角色仍直接进入完整角色卡表单。
- 完整表单继续支持基础、能力值、战斗、豁免、技能、装备、货币和笔记。

## 当前已完成

- `CharacterEditorPage` 新增创建方式选择：
  - 快速创建
  - 标准创建
  - 导入或复制（占位）
- Quick Build 当前支持：
  - D&D 2024 来源提示
  - 职业：战士、法师、游荡者、牧师
  - 物种：人类、精灵、矮人、半身人
  - 背景：士兵、贤者、罪犯、侍祭
  - 等级：1、3、5
  - 自动生成属性、HP、AC、先攻、豁免、技能、装备、货币和创建说明
- Standard Build 当前支持完整步骤导航：
  - 来源
  - 职业
  - 起源
  - 属性
  - 熟练
  - 装备
  - 法术
  - 详情
  - 审核
- Standard Build 可编辑角色名、职业、物种、背景，并实时更新审核摘要。
- Standard Build 可直接创建角色，也可进入完整角色卡表单继续编辑。
- Quick Build 预设已从 UI 文件拆到 domain 层：
  - `character_edit_draft.dart`
  - `quick_build.dart`
- 创建成功后 `CharacterController` 会记录 `lastCreatedCharacter`，页面可消费该状态直接进入新角色详情。
- 设置页新增规则与角色卡偏好：
  - 默认规则集
  - 默认创建方式
  - Legacy 内容显示
  - 字段来源显示
  - 负重显示
  - 默认角色卡标签
- Material 3 主题 seed 调整为更标准的 baseline，并补充主题色说明。
