# D&D 2024 资料驱动角色系统实施计划

> **面向执行者：** 本计划按 TDD 实施；每个行为先增加失败测试，再写最小实现并运行对应测试。

**目标：** 将本地资料库从只读 Wiki 升级为 D&D 2024 角色创建、升级、角色卡与战役动作的唯一规则来源；移除 2014/Legacy 和失效远端资料库兼容链路。

**架构：** 资料正文继续使用 `ContentEntry`，但 v2 资料包为条目附加受限、可校验的 `rules` 声明。客户端的 `CharacterRulesEngine` 根据角色选择、等级和已启用的本地/战役条目生成派生授予账本。角色只持久化选择、手工覆盖与运行时状态；派生属性可随资料更新重新计算，并能回溯到来源条目。

**技术边界：** Flutter / Drift 本地优先；Nest 服务端只同步战役自定义条目、角色战役快照与聊天室活动。项目不附带任何规则正文；导入包自行提供数据。规则目标仅 `dnd5e-2024`。

## 约束

- 不执行任意脚本，不在 JSON 中嵌入 Dart/JavaScript。
- 规则包 v2 必须保留 v1 读取兼容；新创建与新导入默认生成 v2。
- 角色选择使用稳定条目 ID，绝不以显示名称作为规则主键。
- 规则计算必须纯函数、可解释、可测试；UI 不再包含职业名字符串匹配。
- DM 战役私有条目仍走既有战役同步，玩家端合并为只读可用条目。
