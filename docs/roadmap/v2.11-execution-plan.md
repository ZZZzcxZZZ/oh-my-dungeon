# v2.11 多列表紧凑模式执行记录

## 目标

把 `compactLists` 从角色页扩展到更多高频列表，让设置页的 `列表密度` 成为全局可感知的使用偏好，而不是局部功能。跑团过程中，DM 和玩家会频繁扫描战役、场次、资料条目，紧凑模式应减少滚动与卡片噪音。

## 已完成范围

- 战役页：
  - `CampaignsTabPage` 接入 `AppPreferencesController`。
  - 紧凑模式使用更小列表间距、`dense` ListTile 和 `VisualDensity.compact`。
  - 展示 `紧凑战役列表` 标记。
  - 摘要压缩为 `系统 · 角色`，例如 `dnd5e · 主持人`。
- 桌面场次页：
  - `_SessionCard` 支持 `compact` 参数。
  - 紧凑模式展示 `紧凑场次列表` 标记。
  - 摘要压缩为 `日期 · 状态`，例如 `2026-07-09 · 进行中`。
- 资料库页：
  - `ContentLibraryPage` 接入 `AppPreferencesController`。
  - 内容包和可用条目列表支持 `dense` 与 compact visual density。
  - 可用条目展示 `紧凑资料列表` 标记。
  - 摘要保持 `类型 · 来源`，例如 `法术 · SRD`。
- 资料库页顺手修复：
  - 已保存 token 恢复登录后，如果资料库页初始化时认证尚未完成，会在认证状态更新后自动 bootstrap 内容。

## 测试覆盖

- `widget_test.dart`
  - 先写失败测试，验证战役页、桌面场次页、资料库页原本没有紧凑模式标记。
  - 验证 `compactLists=true` 后：
    - 角色页显示 `紧凑角色列表`。
    - 战役页显示 `紧凑战役列表`。
    - 桌面页显示 `紧凑场次列表`。
    - 资料库显示 `紧凑资料列表`。
  - 验证各列表仍显示核心业务摘要。
