# v2.4 场次页角色卡掷骰写入时间线执行记录

## 目标

把 v2.3 的结构化角色卡掷骰事件接入实际跑团场次。玩家在场次中应能直接打开自己的角色卡，从动作页进行常用检定或攻击，并让结果进入当前场次时间线，避免“角色卡结果只存在于本机 SnackBar”。

## 已完成范围

- `SessionDetailPage` 新增 `角色卡` 入口。
- 场次页可从 `CharacterController` 读取本机角色列表，并用底部弹层选择角色。
- 选择角色后进入 `CharacterDetailPage`，保留完整角色卡页签与本地掷骰反馈。
- `CharacterDetailPage.onRoll` 事件会转换为场次消息：
  - `content` 使用 `CharacterRollEvent.summary`
  - `kind` 使用 `roll`
- `SessionController.sendMessage` 新增可选 `kind` 参数，并透传到 `SessionClient.sendMessage`。
- `TableTabPage` 与 `MainShell` 已注入同一个 `CharacterController`，真实 App 路径可复用角色页已有数据。
- 没有角色时，场次页角色卡入口显示 Material 3 风格空状态，引导玩家先创建角色。

## 测试覆盖

- `session_detail_page_test.dart`
  - 先写失败测试，验证 `SessionDetailPage` 原本没有角色卡依赖和入口。
  - 验证从场次页打开角色卡，点击 `察觉 +4` 后向场次发送 `kind: roll` 消息。
  - 验证消息内容进入当前时间线。
- `character_pages_test.dart`
  - 验证角色卡既有动作页、优势 / 劣势、攻击掷骰和编辑器行为无回归。

## 后续建议

- v2.5：为场次时间线提供更清晰的掷骰消息样式，而不是完全复用普通聊天气泡。
- v2.6：将角色卡掷骰事件升级为服务端 `DiceRoll` 或专门 `RollEvent`，支持命中、伤害、优势 / 劣势的结构化展示。
- v2.7：在场次页显示“常用动作”快捷区，让玩家不必每次进入完整角色卡。
