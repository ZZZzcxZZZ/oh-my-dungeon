# 历史档案

本目录只用于追溯，不是当前需求、架构或执行顺序的事实来源。

## 分类

- `roadmap/`：旧 v0.1-v2.x 路线、阶段执行记录和已完成发布清单；
- `agent-prompts/`：已经执行完的并行 Agent 工作提示；
- `handoffs/`：历史交接报告；
- `product/`：已被当前收敛规格替代的早期产品规划和竞品分析；
- `content/`：仍可用于兼容排查、但不再推荐的新建内容格式；
- `superpowers/plans/`：已完成、被替代或停止执行的实现计划；
- `superpowers/specs/`：已被 2026-07-29 收敛规格覆盖的旧设计。

## 使用规则

1. 当前开发从 [`../README.md`](../README.md) 开始。
2. 历史文件保留原文件名，便于 Git 历史和旧链接检索。
3. 历史文档中的版本号不代表发布版本。
4. 历史文档中的 Actor、Room、Session 和战斗入口不代表当前产品模型。
5. 需要恢复历史方案时，必须先与当前架构和 0.1 规格重新对照。
