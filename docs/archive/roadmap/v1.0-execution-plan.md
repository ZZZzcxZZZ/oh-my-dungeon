# v1.0 自托管公测版执行计划

状态：已完成
更新时间：2026-07-09

## 版本目标

让一个朋友团可以长期自托管使用：部署路径清楚、备份恢复可执行、基础管理能力可见、内容资料可迁移、跑团日志可检索，并通过最终全量验证。

## 本版本做

- 完善自托管部署、升级、备份和恢复文档。
- 提供基础 Server Admin 操作说明与客户端入口梳理。
- 内容包支持导出，便于不同服务器之间迁移。
- Session Journal 支持按关键词和类型检索。
- README 明确 v1.0 公测版能力边界与已知限制。
- 最终运行 `npm run doctor`，封版 tag `v1.0.0`。

## 本版本不做

- 真正的插件市场。
- 复杂自动规则引擎。
- 地图战棋。
- 语音视频。
- 全量 E2E 浏览器自动化矩阵。
- 移动端/桌面端安装包签名发布。

## 服务端任务

- 内容库新增导出端点：`GET /api/content/packages/:id/export`。
- Session Journal 新增查询参数：`GET /api/sessions/:id/journal?type=&q=`。
- 保持现有权限边界：内容包导出需要拥有者或战役管理者；Journal 检索需要 Session 可见权限。

## 客户端任务

- 资料库中为内容包提供复制/导出 JSON 入口。
- Session 详情页 Journal 暂不新增完整页面，先保持 API 能力和文档说明。
- 设置页/文档明确 Server Admin 当前能力：注册开关、服务器 profile、本地模式切换。

## 文档任务

- 新增 `docs/deployment/backup-restore.md`。
- 更新 `docs/deployment/self-hosting.md`：Docker Compose、环境变量、升级、反向代理提示。
- 更新 README、当前状态和 agent 指南。
