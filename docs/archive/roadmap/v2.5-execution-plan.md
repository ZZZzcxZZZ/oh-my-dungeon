# v2.5 场次时间线掷骰消息样式执行记录

## 目标

让从角色卡写入场次的掷骰消息在时间线中具备清晰辨识度。跑团中聊天、系统消息、DM 私密消息和掷骰结果会频繁混在一起，掷骰结果需要一眼可见。

## 已完成范围

- `ChatMessage.kind == roll` 的消息在 `SessionDetailPage` 中使用专用样式。
- 角色卡掷骰消息新增：
  - 骰子图标
  - `角色卡掷骰` 标签
  - Material 3 `secondaryContainer` 背景
- 保留原消息内容，不改变服务端协议和历史消息结构。
- 普通聊天、系统消息、DM 可见消息继续沿用原展示逻辑。

## 测试覆盖

- `session_detail_page_test.dart`
  - 先写失败断言，验证时间线原本没有 `角色卡掷骰` 标识。
  - 验证角色卡掷骰发送后，场次时间线显示专用标签。
  - 验证消息仍以 `kind: roll` 发送。

## 后续建议

- v2.6：提供场次页“常用动作”快捷区，直接展示当前角色的核心检定和武器动作。
- v2.7：将 `roll` 消息拆成结构化组件，展示 d20 结果、修正值、总值和伤害。
- v2.8：WebSocket 广播 `roll` 消息后，在其他客户端以同样样式实时显示。
