# v2.15 跑团日志偏好执行记录

## 目标

继续完善设置中心，让角色卡高频运行态操作具备可配置的跑团日志策略。v2.12-v2.14 已把 HP、死亡豁免、休息和状态条件做成角色卡内可直接操作的数据，本版本先补齐客户端偏好：用户可以决定这些运行态变化在在线跑团时是否应写入当前场次日志。

## 已完成范围

- 偏好模型：
  - 新增 `logCharacterRuntimeChanges`。
  - 默认值为 `true`，强调线上跑团的可追溯性。
  - `copyWith` 支持该字段。
- 偏好控制器：
  - 新增 `setLogCharacterRuntimeChanges(bool value)`。
  - 通过现有 `_save` 流程持久化并通知监听者。
- 持久化：
  - `SharedPreferencesAppPreferencesStore` 新增 `app_preferences.log_character_runtime_changes`。
  - `InMemoryAppPreferencesStore` 继续通过完整 `AppPreferences` 对象保存。
- 设置页：
  - 在“跑团偏好”分组新增 `角色状态写入日志` 开关。
  - 文案说明覆盖 HP、休息和状态变化。

## 测试覆盖

- `app_preferences_test.dart`
  - 默认值包含 `logCharacterRuntimeChanges == true`。
  - 修改为 `false` 后重新加载仍保持关闭。
- `widget_test.dart`
  - 设置页展示 `角色状态写入日志`。
  - 点击开关会更新 `AppPreferencesController.preferences.logCharacterRuntimeChanges`。

## 不做事项

- 本版本不把角色卡运行态变化实际写入 Session Log。
- 本版本不改变 `CharacterDetailPage` 的回调签名。
- 本版本不新增服务端 API 或数据库字段。

## 后续建议

- v2.16：在 `SessionDetailPage` 的角色卡抽屉中消费该偏好；开启时把 HP、休息和状态变化写入当前 Session timeline。
- v2.17：把日志项结构化为 `character_runtime_update`，包含字段、旧值、新值、操作者和可见性。
- v2.18：DM 模式支持批量应用状态，并按该偏好写入 Journal / Game Log。
