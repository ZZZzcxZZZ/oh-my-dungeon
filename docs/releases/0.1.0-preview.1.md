# OhMyDungeon 0.1.0 Preview 1

首个公开测试包。适合小范围试用与反馈，**不是稳定版**。

![公开版角色创建向导](https://raw.githubusercontent.com/ZZZzcxZZZ/oh-my-dungeon/main/docs/images/character-builder-public.png)

## 下载

- `ohmydungeon-android-0.1.0-preview.1.apk`：Android 安装包。
- `ohmydungeon-web-0.1.0-preview.1.zip`：静态 Web 文件；需要自行托管，战役协作还需要连接服务端。
- `ohmydungeon-server-linux-0.1.0-preview.1.tar.gz`：Linux Docker Compose 一键部署包，内含预构建镜像，低内存主机无需现场编译。
- `SHA256SUMS`：上述三个文件的完整性校验。

## 可以试什么

- 离线创建、导入、编辑和导出角色卡；角色卡支持 Markdown v2。
- 本地导入内容包，在资料库检索规则条目，并从条目构建角色。
- 连接自托管服务器后，创建或加入战役，使用主聊、私聊、小群、共享档案、角色绑定、掷骰与 DM 快捷操作。
- 本地资料与战役数据分别管理；服务器不可用时本地角色和资料仍可使用。

## 测试边界

- **公开包不含 PHB、MM、DMG 等商业规则正文。** 资料库初始为空；自行导入拥有使用权的资料包后，创建向导才有完整的职业进程与可选项。
- 战斗运行时与 AI Agent 运行时尚未实现。
- 这是预览版；重要角色和战役数据请先备份。服务器升级前备份数据库与 `.env`，不要运行 `docker compose down -v`。
- Android 使用新的本地发布签名。若设备上装的是**同包名、调试签名**的旧测试 APK，不能直接覆盖安装；请先在旧版导出本地备份，再卸载旧版并安装本版。
