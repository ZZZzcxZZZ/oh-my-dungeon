# 统一资料 Schema 与本地自制内容实施计划

## 实施顺序

1. 创建领域层 `ContentSchemaRegistry`，覆盖固定类型、字段定义、筛选定义、规范化和验证。
2. 用注册表替换搜索页、首页分类和详情元数据中的字段硬编码。
3. 扩展 `ContentRepository`，提供不破坏同包其他条目的单条 upsert/delete。
4. 创建 `LocalHomebrewContentService`，负责 ID、revision、包清单和字段校验。
5. 自制内容 GUI 暂缓，不在测试版暴露未完善入口。
6. 增加领域、Repository 和导入回归测试，运行 Flutter 全量验证并重新构建私有 Web 测试版。

## 验收标准

- 自制法术填写环位、学派、职业后立即进入对应筛选。
- 自制子职、职业特性、物品和怪物使用与导入包相同的分类。
- 旧字段别名在写入时迁移为标准字段。
- 未知顶级类型不能由创建器产生；外部旧包未知类型降级为 `custom`。
- 增删一个自制条目不会删除同包其他条目、收藏或笔记。
- 切换账号或服务器后，自制内容随工作区隔离。
