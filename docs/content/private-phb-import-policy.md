# 私有玩家手册导入边界

本项目会支持用户在自己的服务器中管理 D&D 资料库，但开源仓库不得内置或提交商业书籍正文。

## 可以做

- 内置可再分发内容，例如 SRD、Creative Commons、用户原创内容。
- 为 DM 提供 GUI：新增、编辑、导入、启用资料条目。
- 为本地持有 PDF 的用户提供私有导入工具。
- 私有导入工具可以在本机提取目录、名称、分类、页码、简短索引和用户自行确认后的结构化草稿。
- 私有导入产物保存到 `private-imports/` 或 `*.content.private.json`，这些路径默认被 Git 忽略。

## 不可以做

- 不把《玩家手册 2024》或其它商业书籍正文批量提交到仓库。
- 不把商业 PDF 转换成可公开分发的完整资料包。
- 不在测试 fixture 中保存受版权保护的长段落。

## 0.1 实施策略

1. 资料库先提供表单式新增入口，覆盖法术、装备、种族、职业、背景、专长，并写入结构化字段。
2. JSON 导入保留为高级入口。
3. 私有 PDF 导入优先生成只保存在用户本地的索引草稿包；导入到服务器前必须经由 DM 确认。
4. 内置基础资料优先使用开源授权来源；商业 2024 PHB 只作为用户本地私有增强。
