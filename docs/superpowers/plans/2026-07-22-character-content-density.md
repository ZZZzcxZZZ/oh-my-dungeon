# 0.1 角色卡与创建内容密度实施计划

## 任务 1：角色头部与总览

- 为三种视口和长名称编写失败测试。
- 提取响应式角色身份头部与紧凑数值组件。
- 收紧总览间距和操作层级，不改运行时更新接口。

## 任务 2：角色业务列表统一

- 建立角色条目行、空态和尾部操作的共享组件。
- 依次迁移动作、法术、装备、资源和特性。
- 保持所有资料条目使用浮动阅读器。

## 任务 3：创建向导内容层级

- 将角色名和头像集中到详情步骤。
- 统一自动授予、必须选择、来源与错误提示。
- 手机显示当前步骤摘要，审核页显示完整角色摘要。

## 任务 4：验证

- 运行角色页面、规则引擎、升级与内容引用测试。
- 运行 `flutter analyze`、`flutter test`、Web release 和 `npm run doctor`。
