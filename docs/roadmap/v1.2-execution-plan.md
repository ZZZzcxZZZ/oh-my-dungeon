# v1.2 D&D Beyond-like 客户端骨架执行计划

更新时间：2026-07-10

## 目标

把客户端从“功能入口集合”推进到“成熟跑团平台入口”。本版本重点模仿 D&D Beyond 的产品结构：先有首页总览，再进入角色、战役、资料库和桌面；角色卡从单页明细升级为可跑团使用的分区式数字角色卡。

## 本版范围

- 新增首页 Dashboard，作为进入服务器后的默认页。
- 主导航增加“首页”，保留战役、角色、资料库、桌面、设置。
- 角色详情页改为顶部身份与战斗摘要 + Material 3 标签页。
- 角色详情标签覆盖：属性、动作、法术、装备、特性、详情、笔记。
- 首页未登录状态明确提示登录后同步战役、角色和桌面状态。
- 首页登录状态可展示战役、角色、场次数量。
- 保留现有服务端 API，不新增数据库模型。

## 不做事项

- 不做地图 VTT。
- 不做 Quick Builder。
- 不新增官方非开放内容。
- 不重写服务端 Campaign / Session / Encounter 模型。
- 不在本版实现真实角色卡掷骰上报到 Session；动作按钮先作为 UI 入口占位。

## 已完成

- 创建 `docs/product/dnd-beyond-open-source-analysis.md`。
- 新增 `HomeDashboardPage`。
- `MainShell` 默认进入首页。
- `CharacterDetailPage` 改为标签化角色卡。
- Widget 测试覆盖首页默认入口和角色卡标签结构。
- 客户端验证通过：
  - `flutter test`：121 passed。
  - `flutter analyze`：No issues found。
- 服务端 lint 通过：
  - `npm run lint:server`。

## 验收标准

- 打开服务器 profile 后第一屏为“首页 / 跑团总览”。
- 未登录时首页说明登录后可同步战役、角色和桌面状态。
- 角色详情第一屏显示角色身份、HP、AC、先攻、速度和熟练加值。
- 角色详情可通过标签切换属性、动作、法术、装备、特性、详情、笔记。
- 现有客户端测试不回归。

## 下一步

v1.3 进入角色创建器：

- Quick Build：少量关键选择创建一张可玩角色卡。
- Standard Build：分步创建，使用战役允许的内容源。
