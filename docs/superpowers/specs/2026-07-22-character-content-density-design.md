# 0.1 角色卡与创建内容密度设计

## 目标

在新角色壳层之上优化角色卡和创建向导的具体信息密度，使常用操作更快、自动授予更清楚，同时不增加规则范围。

## 角色卡

- 头部只保留头像、姓名、物种/职业/等级和 HP/AC/先攻，窄屏分成稳定两行，宽屏保持单行。
- 总览只呈现 HP、临时 HP、灵感、死亡豁免、休息和状态；属性、技能与资源继续使用独立目标。
- 动作、法术、装备、资源和特性统一使用紧凑列表行，详情继续用浮动阅读器，不进入新页面。
- 新增、编辑、删除使用一致的尾部菜单或图标按钮，空态只提供一个明确主操作。

## 创建向导

- 每一步顶部固定显示步骤名称、简短目标和完成状态，不重复展示长说明。
- 角色名与头像集中到“详情”，其余步骤不重复渲染角色名输入框。
- 自动授予与必须选择分区展示：自动授予只读，缺失选择使用错误色提示并阻止下一步或最终创建。
- 职业与子职业、物种、背景、熟练、装备和法术继续直接读取资料库关系；不添加内置商业规则。
- 手机摘要只显示当前步骤影响的关键数据，完整摘要留在审核页；桌面保留固定摘要列。

## 非目标

- 不改变规则引擎、资料包 schema、角色保存格式或同步协议。
- 不增加 2014 规则支持。
- 不在本轮统一全应用主题。

## 验收

- 360x800、390x844、1280x720 无溢出。
- 角色卡高频操作不超过两次点击。
- 自动授予、待选择、来源条目和创建阻断原因清晰可见。
- 现有角色规则、升级、装备、法术和运行时测试全部通过。
