# v1.7 标准创建审核与缺项提示执行记录

## 目标

让角色创建不再只是表单堆叠，而是能像成熟角色构建器一样告诉玩家“现在完成到了哪一步、还缺什么、是否可以创建”。

## 已完成范围

- 标准创建页完成度从固定值改为实时计算。
- 当前审核项：
  - 来源
  - 职业
  - 起源
  - 属性
  - 详情
- 未填写角色名时显示：
  - `4/5 已完成`
  - `缺少角色名`
  - 创建按钮禁用
- 填写角色名后显示：
  - `5/5 已完成`
  - `创建前检查通过`
  - 创建按钮启用
- 审核摘要下方新增逐项完成状态，降低新玩家漏填关键字段的概率。

## 测试覆盖

- `character_pages_test.dart`
  - 覆盖标准创建页面的实时完成度。
  - 覆盖缺少角色名时的缺项提示。
  - 覆盖创建按钮的启用 / 禁用状态。
  - 保留标准创建提交测试，确认现有创建流程无回归。
