# v2.9 默认角色卡标签偏好落地执行记录

## 目标

让设置页的 `默认角色卡标签` 真正影响角色卡打开体验。玩家在跑团中经常只关心动作、装备、状态或笔记，不应每次打开角色详情后都从属性页重新点击。

## 已完成范围

- `CharacterDetailPage` 新增 `initialTab` 参数。
- `initialTab` 支持以下映射：
  - `overview` → 属性
  - `actions` → 动作
  - `spells` → 法术
  - `equipment` → 装备
  - `status` → 状态
  - `features` → 特性
  - `details` → 详情
  - `notes` → 笔记
- `CharactersTabPage` 接入 `AppPreferencesController`，从角色列表打开角色时使用 `defaultCharacterTab`。
- `SessionDetailPage` 从场次页打开角色卡时同样使用 `defaultCharacterTab`。
- `MainShell` 透传同一个偏好控制器，保证设置页与角色 / 场次入口共用同一份本地设置。
